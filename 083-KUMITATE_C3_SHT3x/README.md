# KUMITATE-C3 温湿度モニター

KUMITATE-C3にSHT30温湿度センサーをI2C接続し、温度と湿度を本体OLEDに表示するサンプルです。

基板上のSW4を押すと、現在の温湿度を表示する「リアルタイムモニタ」と、直近5分間の温度変化を確認できる「温度推移グラフ」が切り替わります。

## 主な機能

- SHT30から温度と湿度を取得
- OLEDに温度を`TEMP`、湿度を`HMD`として表示
- 温湿度の表示を約1秒ごとに更新
- 温度を10秒間隔で記録
- 直近5分間の温度を折れ線グラフで表示
- 基板上のSW4で表示画面を切り替え
- シリアルモニタにも測定値を出力

## 表示画面

### リアルタイムモニタ

現在の温度と湿度を表示します。

```text
TEMP  24.5 C
HMD   52.1 %
```

- `TEMP`：温度
- `HMD`：湿度
- `C`：摂氏温度
- `%`：相対湿度

### 温度推移グラフ

温度を10秒ごとに記録し、直近5分間の変化を折れ線グラフで表示します。

- 記録間隔：10秒
- 表示期間：直近5分間
- 保存点数：31点
- 縦軸：履歴内の最低温度から最高温度まで自動調整
- 横軸：5分前から現在まで

起動直後は履歴が少ないため、測定点が少しずつ増えていきます。約5分経過するとグラフ全体が埋まり、その後は古いデータから順番に更新されます。

## 使用するもの

| 部品 | 数量 | 備考 |
|---|---:|---|
| KUMITATE-C3 | 1 | OLED搭載ボード |
| SHT30温湿度センサー | 1 | 3.3Vで使用できるモジュール |
| ジャンパーワイヤー | 4 | SHT30の接続に使用 |

## 配線

SHT30と本体OLEDは同じI2Cバスを共有します。

| SHT30 | KUMITATE-C3 | 説明 |
|---|---|---|
| VCC | 3.3V | 電源 |
| GND | GND | グランド |
| SDA | IO1 | I2Cデータ |
| SCL | IO2 | I2Cクロック |

画面切り替えには、KUMITATE-C3基板上のSW4を使用します。

| 機能 | GPIO |
|---|---:|
| SW4 | IO8 |
| OLED SDA | IO1 |
| OLED SCL | IO2 |

> SHT30は3.3Vで使用してください。使用するモジュールの対応電圧と端子配列は、接続前に製品仕様を確認してください。

## I2Cアドレス

| 機器 | 標準アドレス |
|---|---|
| 本体OLED | `0x3C` |
| SHT30 | `0x44` |

SHT30モジュールの設定によっては、アドレスが`0x45`の場合があります。`0x44`で認識されないときは、プログラムの初期化部分を変更してください。

```cpp
sht30.begin(0x45);
```

## 必要なライブラリ

Arduino IDEのライブラリマネージャーから、以下のライブラリをインストールします。

- `U8g2` by oliver
- `Adafruit SHT31 Library` by Adafruit

依存ライブラリのインストールを確認された場合は、一緒にインストールしてください。

## Arduino IDEの設定

代表的な設定例です。KUMITATE-C3で通常使用している設定がある場合は、そちらを優先してください。

```text
ボード: ESP32C3 Dev Module
Upload Speed: 921600 または 460800
USB CDC On Boot: Enabled
シリアルモニタ: 115200 baud
```

## 使い方

1. SHT30をKUMITATE-C3へ接続します。
2. 必要なライブラリをインストールします。
3. Arduino IDEでプログラムを開きます。
4. KUMITATE-C3へプログラムを書き込みます。
5. OLEDの`TEMP`と`HMD`に測定値が表示されることを確認します。
6. 基板上のSW4を押し、温度推移グラフへ切り替えます。
7. もう一度SW4を押すと、リアルタイムモニタへ戻ります。

## 画面の切り替え

SW4を押すたびに表示モードが切り替わります。

```text
TEMP・HMDリアルタイム表示
            ↓ SW4
       温度推移グラフ
            ↓ SW4
TEMP・HMDリアルタイム表示
```

SW4はIO8に接続されています。プログラムでは内部プルアップを使用し、押されたときに`LOW`として判定します。

```cpp
#define SWITCH_PIN 8

pinMode(SWITCH_PIN, INPUT_PULLUP);
```

## グラフの仕組み

温度履歴は、31個の要素を持つリングバッファに保存します。

```cpp
const unsigned long GRAPH_INTERVAL_MS = 10000;
const int HISTORY_SIZE = 31;
```

10秒ごとに1点を記録し、0秒から300秒までの31点で5分間を表します。保存領域がいっぱいになると、最も古い測定値へ新しい測定値を上書きします。そのため、メモリ使用量を増やさずに直近5分間のデータを保持できます。

グラフの縦軸は、履歴内の最低温度と最高温度から自動的に決まります。温度変化が小さい場合も確認できるように、一定の表示幅を確保します。

## シリアルモニタ

シリアルモニタを`115200 baud`で開くと、測定値を確認できます。

```text
TEMP: 24.5 C  HMD: 52.1 %
```

## OLEDの単位表示

使用するOLEDフォントに`℃`が収録されていない場合があるため、画面上では温度の単位を`C`で表示します。湿度の単位は`%`です。

画面表示を英数字の`TEMP`と`HMD`に統一することで、日本語フォントに含まれない文字による文字化けを避けています。

## トラブルシューティング

### SHT30が見つからない

- VCC、GND、SDA、SCLの配線を確認してください。
- SDAがIO1、SCLがIO2へ接続されていることを確認してください。
- I2Cアドレスを`0x44`から`0x45`へ変更して確認してください。
- 使用するSHT30モジュールが3.3Vに対応していることを確認してください。

### OLEDに何も表示されない

- OLEDのI2Cアドレスが`0x3C`になっていることを確認してください。
- `Wire.begin(1, 2)`がOLEDやSHT30の初期化より前に実行されていることを確認してください。
- U8g2ライブラリが正しくインストールされていることを確認してください。

### SW4を押しても画面が変わらない

- SW4のGPIOがIO8に設定されていることを確認してください。
- `pinMode(SWITCH_PIN, INPUT_PULLUP)`が実行されていることを確認してください。
- スイッチのチャタリング対策処理を確認してください。

### グラフに線が表示されない

起動直後は履歴が1点しかないため、線ではなく測定点だけが表示されます。複数の測定値が保存されると線が表示されます。

## カスタマイズ

記録間隔は次の値で変更できます。

```cpp
const unsigned long GRAPH_INTERVAL_MS = 10000;
```

表示期間や記録間隔を変更した場合は、履歴数も調整してください。

```text
履歴数 = 表示期間 ÷ 記録間隔 + 1
```

例として、5秒間隔で5分間表示する場合は61点です。

```cpp
const unsigned long GRAPH_INTERVAL_MS = 5000;
const int HISTORY_SIZE = 61;
```
