# KUMITATE-C3 firmware

KUMITATE-C3のファクトリーテストとMaker Faire向けデモを、1つのArduinoプロジェクトにまとめたファームウェアです。

## 起動モード

- 起動画面で何も押さない：5秒後にデモプログラム
- 起動画面でSW1とSW4を約1秒同時長押し：ファクトリーテスト
- 起動画面でSW2とSW3を約1秒同時長押し：NVS記録消去の確認画面を開く

起動画面は約5秒表示されます。SW2とSW3の長押しだけでは記録を消去しません。確認画面でSW1（はい）を押すと消去し、SW2（いいえ）を押すと取り消して通常起動します。記録消去では`kumitate`名前空間を消去するため、反射ゲームの直前得点と最高得点、記憶ゲームの最高レベル、10秒ゲームの最小誤差が初期化されます。ファクトリーテストのプログラム自体や基板設定は消去されません。

## デモメニュー

- SW1：10ラウンド反射神経ゲーム（緑は押す、赤は押さない）
- SW2：記憶ゲーム
- SW3：4桁の暗号解除ゲーム
- SW4：10秒ぴったりゲーム

待機中はRGB LEDが低輝度で流れます。各デモ終了後はメニューへ戻ります。

暗号解除ゲームでは、SW1～SW4を数字1～4として4桁の暗号を入力します。同じ数字が複数含まれる場合もあります。各回答後に「位置も一致」と「数字だけ一致」の個数が表示され、10回以内に正解すると解除成功です。ヒント画面は自動では切り替わらず、いずれかのスイッチを押すと次の回答へ進みます。以前の8ステップ光・音シーケンサーはメニューからは呼び出しませんが、`DemoProgram::sequencer()`としてソースコードに残しています。

10秒ぴったりゲームは、SW1で計測を開始し、体感で10秒になったところでもう一度SW1を押します。開始から2秒間だけOLEDへ経過時間を表示し、2秒を過ぎると時間を非表示にします。実測時間と10秒との差を表示し、最小誤差をNVSの`timingBest`へ保存します。新記録ではお祝い演出を再生します。SW1以外で停止した結果は記録対象外です。以前の光と音のショーはメニューからは呼び出しませんが、`DemoProgram::lightShow()`としてソースコードに残しています。

メニューでスイッチを押して各モードへ入る際は、待機中のRGBアニメーションを4灯すべて消してから選択した処理を開始します。

反射神経ゲームは、緑に点灯したRGB LEDの真下にあるスイッチを押します。全10ラウンドのうち、赤色フェイントはランダムな位置に必ず2回だけ出現します。赤では何も押しません。緑は200msまで100点で、それ以降は10ms遅くなるごとに1点減点（最低10点）されます。赤を正しく無視すると75点、赤で押すと-100点、緑で違うスイッチを押すと-50点、時間切れは0点です。最高得点は950点です。直前の合計得点と最高得点はESP32-C3のNVSへ保存されるため、電源を切っても保持されます。最高記録を更新すると、日本語の新記録表示、RGB演出、お祝いファンファーレを再生します。

各ラウンド終了時には、現在までの1ラウンド平均と、NVSに保存された最高得点の1ラウンド平均を比較します。現在平均が上回っている間はOLEDに「好調！記録ペース」と表示し、水色のRGB全灯と短い上昇音で知らせます。

記憶ゲームでは、連続でクリアしたレベル数を記録として扱います。最高到達レベルをNVSの`memoryBest`へ保存し、開始画面に表示します。最高レベルを更新した場合は「新記録！」を表示し、反射ゲームと同じRGB演出とお祝いファンファーレを再生します。最高レベルは16です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `KUMITATE_C3.ino` | Arduinoの`setup()`と`loop()`、起動モード選択 |
| `PinDefinitions.h` | 共通GPIO、OLEDアドレス、RGB輝度 |
| `FactoryTest.h/.cpp` | OLED操作式ファクトリーテスト |
| `DemoProgram.h/.cpp` | 展示用メニューと4種類のデモ |

## 必要なライブラリ

- Adafruit GFX Library
- Adafruit SSD1306
- Adafruit NeoPixel
- U8g2 for Adafruit GFX（日本語OLED表示）

Arduino IDEでこのフォルダーの`KUMITATE_C3.ino`を開き、ESP32-C3へ書き込みます。ボード設定では`USB CDC On Boot: Enabled`を推奨します。
