# KUMITATE-C3 学習赤外線リモコン

ESP32-C3で赤外線リモコンの信号を受信・保存し、再送信するArduinoスケッチです。OLEDと4つのスイッチで操作します。

## 主な機能

- 最大20スロットに赤外線信号を登録。
- 受信したRAWタイミング（点灯・消灯の時間列）を保存して送信。
- Save操作でNVS（内蔵フラッシュ）へ保存し、再起動後に復元。
- シリアルモニターから各スロットに最大4文字の名前を設定。
- スロット名もNVSに保存し、OLEDの選択画面に番号と一緒に表示。

## 必要なもの

- KUMITATE-C3（ESP32-C3）
- SSD1306搭載の128×64ドットI²C OLED
- 赤外線受信モジュール（VS1838B／HX1838など）
- 赤外線送信用LED（使用例：940nm）と電流制限抵抗
- スイッチ4個と外付けプルアップ抵抗
- Arduino IDEとESP32用ボードパッケージ

使用ライブラリ：

- `U8g2`
- `IRremote`（`IRremote.hpp`を使用）
- `Preferences`、`Wire`（ESP32用ボードパッケージに付属）

受信モジュールと送信用LEDは別の部品です。部品の端子配列と定格は、使用する製品の資料を確認してください。

## ピン割り当て

| 用途 | GPIO |
| --- | ---: |
| OLED SDA | 1 |
| OLED SCL | 2 |
| SW1 | 21 |
| SW2 | 3 |
| SW3 | 9 |
| SW4 | 8 |
| 赤外線送信 | 6 |
| 赤外線受信 | 7 |

スイッチは、離すとHIGH、押すとLOWになる配線を前提としています。スケッチの設定は`INPUT`で、外付けプルアップを使用します。

送信側の使用例：

```text
GPIO6 → 赤外線LEDのアノード
赤外線LEDのカソード → 220Ω → GND
```

これはGPIOから直接駆動する構成です。電流制限抵抗を変更する場合は、LEDとGPIOの許容電流を確認してください。

## 書き込み

1. Arduino IDEで`085-KUMITATE-C3_REMOTE_CONTROLLER.ino`を開きます。
2. 必要なライブラリをインストールします。
3. 使用するESP32-C3に対応したボード設定とポートを選択します。
4. コンパイルして書き込みます。
5. 起動するとOLEDに`IR REMOTE`と表示されます。

ファイルには無効化された試験用コードも含まれます。先頭の`#if 1`で選択されている学習リモコン部分を使用してください。

## ボタン操作

| 画面 | SW1 | SW2 | SW3 | SW4 |
| --- | --- | --- | --- | --- |
| メイン | 受信待機へ | — | — | 送信選択へ |
| 受信待機 | メインへ戻る | — | — | — |
| 受信後の保存先選択 | メインへ戻る | 選択スロットへ保存 | 前のスロット | 次のスロット |
| 送信選択 | メインへ戻る | 選択スロットを送信 | 前のスロット | 次のスロット |

スロット番号は01～20です。01の前は20、20の次は01に戻ります。

### 赤外線信号を登録する

1. メイン画面でSW1を押します。
2. `Waiting IR...`が表示されたら、登録したいリモコンを受信部に向けてボタンを押します。
3. `IR RECEIVED`画面でSW3／SW4を使い、保存先を選びます。
4. SW2を押します。
5. `SAVED`と表示され、受信待機へ戻ります。

同じスロットに保存すると、以前の赤外線データを上書きします。保存に失敗した場合は`SAVE FAILED`と表示し、保存先選択画面に戻ります。

### 保存した信号を送信する

1. メイン画面でSW4を押します。
2. SW3／SW4で送信するスロットを選びます。
3. 送信用LEDを対象機器に向けてSW2を押します。

送信中は`SENDING`と表示します。未登録のスロットは`--- EMPTY ---`、送信操作時は`EMPTY`と表示します。

## スロット名を設定する

シリアルモニターを次の設定で開きます。

- 通信速度：**115200bps**
- 行末：**改行あり**（LF、CR、CRLFのいずれも可）

次の形式で1行ずつ送信します。引用符は付けません。

```text
番号 名前
```

例：

```text
01 TV
02 A/C
03 LAMP
20 FAN
```

- 番号は必ず2桁の`01`～`20`。
- 番号と名前の間に半角スペースを1つ入れます。
- 名前は半角英数字・記号で1～4文字。日本語は使えません。
- 名前内の半角スペースも文字数に含みます。スペースだけの名前は受け付けません。
- 5文字以上や不正な入力はエラーになり、元の名前を保持します。
- 同じ番号で入力し直すと名前を変更できます。

成功するとシリアルモニターに次のように表示します。

```text
NAME SAVED 01 TV
```

OLEDの保存先・送信選択画面では、次のように表示します。

```text
<01> TV
```

表示中のスロットの名前を変更すると、その画面も更新します。メイン画面にはスロット名を表示しません。

名前は入力成功時にNVSへ保存されるため、SW2で改めてSaveする必要はありません。赤外線未登録のスロットにも名前を設定できますが、名前だけでは送信できません。

## NVSへの保存

赤外線データとスロット名は別々に保存します。名前を変更しても赤外線データは変わらず、赤外線データを上書きしても名前は残ります。

- 名前空間：`ir-remote`
- 赤外線データのキー：`slot00`～`slot19`
- 名前のキー：`name00`～`name19`

キー末尾は0始まりで、OLED上の01～20に対応します。起動時に読み戻し、保存されていないスロットは空として扱います。

通常の電源OFFや再起動ではデータは保持されます。フラッシュ全消去やNVS領域を変更する操作では消える場合があります。現在、スロット削除・名前削除・全消去の操作は実装していません。

## エアコンの長い信号への対応

エアコンのリモコンは長い信号を送ることがあり、RAWタイミング配列の上限が200では途中で切れる場合があります。今回の使用環境では、144ビットの信号で`RAW length = 200`となり、バッファを400に増やして再登録すると動作しました。

**このREADME作成時点の同梱スケッチは`MAX_RAW_LENGTH 200`のままです。エアコンで使用する場合は、動作確認できた以下の設定を反映してください。**

ライブラリ読み込み前：

```cpp
#define NO_LED_FEEDBACK_CODE
#define RAW_BUFFER_LENGTH 400
#include <IRremote.hpp>
```

保存用配列の定義：

```cpp
#define MAX_RAW_LENGTH 400
```

`RAW_BUFFER_LENGTH`は受信ライブラリ側、`MAX_RAW_LENGTH`は保存・送信用の上限です。RAWの長さはビット数ではなく、点灯・消灯時間の要素数です。

変更後は対象の信号を**再受信してSaveし直してください**。すでに途中で切れて保存された信号は、自動では修復されません。400で全機種に対応できるわけではありません。

## SW4とLEDフィードバック

次の設定を`IRremote.hpp`の読み込み前に置いてください。

```cpp
#define NO_LED_FEEDBACK_CODE
#include <IRremote.hpp>
```

この設定は、IRremoteによる動作表示用LEDの制御を除外します。今回の環境では、LEDフィードバックのピン使用がSW4と競合し、SW4が反応しなくなる問題をこの設定で解消しました。

赤外線送信そのものを無効にする設定ではありません。

## 制約・確認事項

- 送信の搬送波周波数はコード内で**38kHz固定**です。元の信号の搬送波周波数を測定・保存する機能はありません。
- RAWデータが保存用上限を超えた場合、現在の実装では切り詰めます。受信ログの長さが上限と一致する場合は、切り捨てを確認してください。
- NVSの空き容量が不足すると保存に失敗します。長い信号を多数登録する場合は`SAVE FAILED`やシリアルログを確認してください。
- エアコンでは温度・モードなどを含む状態全体が送信されることがあります。保存した信号は、受信時の設定を再現するためのものとして扱ってください。
- コンパイル・実機での確認は使用環境で行ってください。NVSと名前設定を追加した配布版は、この作成環境ではコンパイル・実機確認を行っていません。
