# KUMITATE-C3 サンプルプログラム集

ESP32-C3を搭載した学習ボード「KUMITATE-C3」で使用するArduinoサンプルプログラム集です。

LED、スイッチ、ブザー、OLED、Wi-Fi通信など、組み込みプログラミングの基礎から応用まで、実機を動かしながら学習できます。
